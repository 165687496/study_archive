# RC 파트별 강약점 1차 진단

## 목표
- 2026-09-20 TOEIC 900점 초과를 위해 RC에서 문법·어휘·독해 중 무엇이 점수를 막는지 1차 진단한다.

## 예측 — 내가 먼저 답한 것
- "강점 : 문법? / 약점 : 해석 속도 / 이유 일단 파트별로 특정 부분이 문제인지 기출 풀이를 많이 안해서 모르겠고, 강점과 약점에 대한 확신도 많이 없는 상태이다."
- "보증 기간이 만료되었으니까 교체하는거 아니야?? 아 보증이라는게 아.... 일단 보증이 만료되었으니 제조업체가 교체해줘야겠구나라는 의미로 받아들였는데, 보증기간이 만료되기 전에 교체해줄 수 있는거니까 even though가 필요하다는거 정말 이해했어. 한국말 이슈인 것 같아..."
- "7번은 첫번째 문장과 두번째 문장 읽고 d를 골랐는데, monthly inventory spreadsheets 대신해서 new inventory portal을 사용한다고 해서 monthly inventory reports의 필요를 대체한다라는 d를 골랐어."
- "C야 더이상 비용 영수증을 직접 제출하는 것이 아니라 스캔해서 회사 웹사이트에 직접 올려야하는 방식으로 바뀌었어."
- "C / the training session scheduled for Thursday will be moved from the main auditorium to Conference Room B. 라는 문장에서 다른 지역으로 장소가 바뀌었다는 사실을 알 수 있어"
- "답은 B이고, 카페가 새 주방 장비를 설치하기 위해 3시에 문을 닫아서 2시반 이후에 오는 모든 온라인 주문들이 다 다음날 토요일 아침에 준비될거라고 했기 때문이야"
- "답은 D인것 같아. meetings involving visiting clients에는 requirement가 적용되지 않아서야. 근데 내가 궁금한 것은 B도 될 수 없느냐야. reservations made less than 24 hours가 approval을 필요로 하는거니까, 이틀 전에 미리 예약을 한 것 또한 매니저의 승인이 필요없지 않을까라는 생각이 들었어"

## 오늘 직접 학습한 지식
1. 품사 문제에서 conclusive와 effective가 형용사 자리에 들어간다는 것을 근거로 설명할 수 있었다.
2. even though는 보증 기간이 만료되었는데도 무상 교체한다는 역접 관계를 나타낸다는 것을 이해했다.
3. 새 inventory portal이 월별 보고서 자체를 없애는 것이 아니라 제출 방식을 이메일에서 포털 업로드로 바꾼다는 점을 설명했다.
4. will be moved from A to B와 will take place in a different location의 패러프레이즈 관계를 찾았다.
5. 2시 30분 이후 주문은 다음 날 아침 준비된다는 시간 관계를 적용해 토요일 아침이라는 답을 골랐다.
6. 24시간 전 예약 규칙과 visiting clients 예외 규칙을 동시에 적용해 복수 정답이 되는 문제 오류를 발견했다.

## 교정 및 보완
- RC 미니 진단은 8문제 중 6문제 정답이었다. Part 5는 3/4, Part 6은 2/2, Part 7은 1/2였다.
- 4번 오답은 접속사 문법 부족보다 warranty period의 현실 의미를 반대로 해석한 배경 개념 오류에 가까웠다.
- 7번 오답은 제출 방식의 변경을 보고서 필요성의 폐지로 확대 해석한 범위 오류였다.
- location은 해당 문맥에서 "지역"보다 "장소"가 자연스럽다.
- 조건·예외 문제에서 B와 D가 모두 승인 불필요가 되어 단일 정답형 문제가 성립하지 않았다. 사용자가 이 오류를 정확히 지적했다.

## 퀴즈
- Q1: Employees requesting reimbursement must submit all receipts _____ ten business days. / 내 답: A(within), 확신도 B / 채점: 정답.
- Q2: information was not sufficiently _____. / 내 답: B(conclusive), 확신도 A / 채점: 정답.
- Q3: one of the company’s most _____ negotiators / 내 답: C(effective), 확신도 A / 채점: 정답.
- Q4: warranty period has already expired / 내 답: B(unless), 확신도 B / 채점: 오답. even though가 역접 관계를 만든다.
- Q5: entrance will remain closed _____ repairs are completed / 내 답: B(until), 확신도 A / 채점: 정답.
- Q6: additional security personnel의 목적 / 내 답: C, 확신도 A / 채점: 정답.
- Q7: new inventory portal에 대한 정보 / 내 답: D, 확신도 B / 채점: 오답. 정답은 B이며 오류 자동 점검 기능이 근거다.
- Q8: tomorrow에 일어날 일 / 내 답: C, 확신도 A / 채점: 정답.
- 재검증: 영수증 직접 제출에서 웹 업로드로 바뀐 절차 / 내 답: C / 채점: 제출 방식과 제출 의무를 정확히 분리함.
- 재검증: 교육 장소 변경 패러프레이즈 / 내 답: C / 채점: 정답. moved from A to B와 different location의 대응을 설명함.
- 재검증: 금요일 오후 4시 온라인 주문 / 내 답: B / 채점: 정답. 시간 관계 추론 성공.

## 취약 영역
- 일부 절차의 변화를 전체 필요성의 폐지로 확대 해석하는 경향
- 현실 배경 개념이 문장 논리 해석에 개입할 때 생기는 오류
- 실제 시험 환경에서의 RC 풀이 속도는 표본이 부족해 아직 판단 불가
- Part 5·6·7별 강약점은 더 많은 기출형 표본이 필요함

## 다음 복습 질문
1. 제출 방식이 바뀐 것과 제출 의무가 사라진 것을 어떻게 구분할 수 있는가?
2. even though와 unless가 만드는 논리 관계를 각각 설명할 수 있는가?
3. Part 7 선택지에서 지문보다 범위를 넓힌 표현을 어떻게 찾아낼 것인가?
4. 제한 시간 안에서 Part 5·6·7별 정답률과 오답 원인은 어떻게 달라지는가?

## 개념 지도
### TOEIC Part 5 문법·논리
- 품사 판단 ← 문장 구조, 수식 관계
- even though ← 역접, 절과 절의 의미 관계
- unless ← 조건, 예외 조건

### TOEIC Part 7 독해
- 제출 방식과 제출 의무의 구분 ← 절차 변화, 범위 통제
- 패러프레이즈 대응 ← moved from A to B, different location
- 시간 관계 추론 ← after, following morning, 요일 계산
- 조건·예외 적용 ← 기본 규칙, 예외 규칙
- 선택지 범위 오류 ← 일부 변화, 전체 폐지

### TOEIC collocation
- place an order ← order, 온라인 주문 문맥
- make a reservation ← reservation, in advance
- reach an agreement ← agreement, negotiation
