# TOEIC 시간 전치사와 품사 복원

## 목표
- TOEIC의 기본 시간 전치사와 품사 문제 풀이 감각을 복원한다.

## 예측 — 내가 먼저 답한 것
- Q1. B 요일에 사용되는 전치사가 on이라서? 명확하게 설명은 못하겠고 당연하게 느껴지는 것 같아
- Q2. C 앞에 관사인 a가 있고 뒤에 명사가 있으므로 형용사가 오는 것이 자연스럽고, 인상을 주는 발표를 했다는 의미가 되니, B가 아닌 C가 오게 돼.
- Q3. B 9시까지 도착해달라는 의미가 필요하므로 by로 골랐어
- Q4. A, C / to 뒤에는 명사가 오면 전치사, 동사가 오면 to부정사로 활용된다.
- 마지막 문제: at가 자연스럽게 느껴지지만 왜 on이 안 되는지는 명확히 설명하지 못하겠다.

## 오늘 직접 학습한 지식
1. by는 마감 시점을 나타낸다.
2. at은 시각, on은 날짜·요일, in은 기간을 나타낸다.
3. easy to + 동사원형은 형용사 뒤의 to부정사 구조이다.
4. 품사 문제는 문장 구조를 먼저 본다.

## 교정 및 보완
- on Friday와 by Friday의 의미 차이를 구분했다.
- easy to user는 문법적으로 성립하지 않는다.
- at 2 p.m.는 시각, by 2 p.m.는 마감 시점이다.

## 퀴즈
- Q1: on/by Friday / 내 답: on / 채점: 오답
- Q2: impressive / 내 답: impressive / 채점: 정답
- Q3: arrive by 9 a.m. / 내 답: by / 채점: 정답
- Q4: easy to use / 내 답: A,C / 채점: 부분 이해
- Q5: begin at 2 p.m. / 내 답: at / 채점: 정답

## 취약 영역
- 시간 전치사를 의미 기준으로 설명하기.
- to가 전치사인지 to부정사인지 빠르게 구분하기.

## 다음 복습 질문
1. at/on/in/by 차이를 설명할 수 있는가?
2. by와 until의 차이를 설명할 수 있는가?

## 개념 지도
### TOEIC 문법
- 시간 전치사 ← 시각, 날짜·요일, 기간
- by(마감 시점) ← 시간 전치사
- 품사 판단 ← 문장 구조
- to부정사 ← 동사원형
